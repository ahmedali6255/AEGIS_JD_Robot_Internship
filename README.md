# AEGIS_JD_Robot
Part of AEGIS-JD — a multi-modal AI system for the EZ-Robot JD Humanoid, built by a 5-member team (gesture/emotion/speech control, facial recognition + security gate, conversational AI, object detection, PID tracking). This repo: my module — real-time object detection (YOLOv8), Gemini-based reasoning, and PID servo tracking.
